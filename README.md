## Overview

**Code DNA** is an intelligent, full-stack code review and engineering intelligence platform. Unlike conventional static analyzers or generic AI chat wrappers, Code DNA learns from team policies and developer behavior over time. It identifies recurring anti-patterns, forecasts code regression risks, runs interactive Code Battles with Google Gemini, and visualizes developer evolution through a personalized **Developer Code DNA Profile**.

---

## Core Capabilities

1. **Multi-Language Code Review**:
   - Deterministic syntax, security, and maintainability static analysis across 10 major languages: **JavaScript, TypeScript, Python, Java, C++, C, Go, Rust, PHP, and SQL**.
   - Robust language-source consistency validation preventing cross-language mismatches.
2. **Deterministic Quality Scoring (1.0–10.0)**:
   - Transparent, mathematical penalty scoring evaluating Correctness, Security, Maintainability, Performance, and Architecture.
3. **Google Gemini Intelligence Engine**:
   - Deep contextual code analysis powered by Google Gemini (`gemini-3.6-flash`), with resilient, deterministic static fallback when quota is exhausted.
4. **Historical Engineering Memory**:
   - Institutional memory that retrieves and applies organizational coding policies, standards, and past review learnings to current code submissions.
5. **Developer Code DNA Profile**:
   - Longitudinal profiling that fingerprints engineer strengths, habits, blind spots, and month-over-month craft evolution.
6. **Predictive Code Risk Forecast**:
   - Multi-factor risk calculation predicting regression probability, fragility, and complexity hazards before code reaches production.
7. **Code Battle Engine**:
   - Side-by-side interactive code optimization comparing original developer code against an optimized alternative generated by Google Gemini.
8. **Engineering Achievements & Gamification**:
   - Authentic XP, levels, and badge unlock mechanisms driven strictly by verified code review events and quality milestones.

## Tech Stack

- **Frontend**: Next.js 14 (App Router, Standalone), React 18, TypeScript, Tailwind CSS, Monaco Editor, Lucide React, Axios.
- **Backend**: Node.js 20, Express, TypeScript, Zod, Helmet, CORS, Cookie-Parser, Morgan, Mongoose.
- **AI**: Google Gemini API (`gemini-3.6-flash`).
- **Database**: MongoDB Atlas.
- **Authentication**: Stateless JSON Web Tokens (JWT) with dual-mode HTTP-only cookies and Authorization Bearer headers.
- **Deployment**: Google Cloud Run (Containerized via multi-stage Alpine Dockerfiles).

## Local Development

### Prerequisites

- Node.js v18+ or v20+
- npm v9+
- MongoDB Atlas cluster or local MongoDB instance
- Google Gemini API key ([Google AI Studio](https://aistudio.google.com/))

### 1. Backend Setup

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

The backend server will start on `http://localhost:5000` (or `PORT` in `.env`).  
Verify health:
```bash
curl http://localhost:5000/api/health
```

### 2. Frontend Setup

```bash
cd frontend
cp .env.local.example .env.local
npm install
npm run dev
```

The frontend will start on `http://localhost:3000`.

## Environment Variables Reference

### Backend (`backend/.env`)

| Variable | Description | Example / Default |
| :--- | :--- | :--- |
| `PORT` | HTTP port for backend server | `5000` (Local) / `8080` (Cloud Run) |
| `NODE_ENV` | Environment mode | `development` / `production` |
| `MONGODB_URI` | MongoDB connection string | `mongodb+srv://...` |
| `JWT_SECRET` | Secret key for signing authentication tokens | 32+ character random string |
| `AI_PROVIDER` | Primary AI provider | `gemini` |
| `GEMINI_API_KEY` | Google Gemini API Key | Secret key from Google AI Studio |
| `GEMINI_MODEL` | Google Gemini Model name | `gemini-3.6-flash` |
| `FRONTEND_URL` | Allowed frontend origin for CORS | `http://localhost:3000` (Local) / Live URL |

### Frontend (`frontend/.env.local` / Docker Build Arg)

| Variable | Description | Example / Default |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_API_URL` | Base URL of the backend API | `http://localhost:5000/api` / Live Backend URL |

## Google Cloud Production Deployment Guide

CodeDNA is designed to run natively on **Google Cloud Run** as two lightweight serverless containers.

### Step 1: Pre-requisites & MongoDB Atlas Configuration

1. In the **MongoDB Atlas Console**, navigate to **Network Access**.
2. Ensure IP Access List includes `0.0.0.0/0` (required for dynamic Cloud Run egress IPs).
3. Set your Google Cloud Project ID in Cloud Shell:
   ```bash
   gcloud config set project YOUR_PROJECT_ID
   ```
4. Enable required Google Cloud APIs:
   ```bash
   gcloud services enable run.googleapis.com cloudbuild.googleapis.com artifactregistry.googleapis.com
   ```

---

### Step 2: Deploy Backend to Cloud Run

Deploy the backend container directly from source using Google Cloud Build:

```bash
cd backend

gcloud run deploy codedna-backend \
  --source . \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars "NODE_ENV=production,AI_PROVIDER=gemini,GEMINI_MODEL=gemini-3.6-flash" \
  --set-env-vars "MONGODB_URI=YOUR_MONGODB_URI_HERE" \
  --set-env-vars "JWT_SECRET=YOUR_JWT_SECRET_HERE" \
  --set-env-vars "GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE" \
  --set-env-vars "FRONTEND_URL=https://placeholder-url.a.run.app"
```

> **Note**: Take note of the deployed backend URL (e.g. `https://codedna-backend-xxxxxx-uc.a.run.app`).

Verify backend health:
```bash
curl https://codedna-backend-xxxxxx-uc.a.run.app/api/health
```

---

### Step 3: Deploy Frontend to Cloud Run

Build and deploy the Next.js frontend with the live backend URL passed via Cloud Build:

```bash
cd ../frontend

# 1. Build container with backend URL baked in
gcloud builds submit \
  --tag gcr.io/YOUR_PROJECT_ID/codedna-frontend:latest \
  --substitutions=_NEXT_PUBLIC_API_URL="https://codedna-backend-xxxxxx-uc.a.run.app/api" \
  .

# 2. Deploy to Cloud Run
gcloud run deploy codedna-frontend \
  --image gcr.io/YOUR_PROJECT_ID/codedna-frontend:latest \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated \
  --port 8080
```

> **Note**: Take note of the deployed frontend URL (e.g. `https://codedna-frontend-xxxxxx-uc.a.run.app`).

---

### Step 4: Update Backend CORS with Live Frontend URL

Update `codedna-backend` with the real frontend origin:

```bash
gcloud run services update codedna-backend \
  --region us-central1 \
  --update-env-vars "FRONTEND_URL=https://codedna-frontend-xxxxxx-uc.a.run.app"
```

---

### Step 5: Verification

Open `https://codedna-frontend-xxxxxx-uc.a.run.app` in your browser:
- Register an account
- Submit code for review
- Check Developer DNA
- Play a Code Battle with Gemini
